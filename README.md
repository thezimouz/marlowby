# Marlowby

BPA Website Design & Development Team project.

Live site: https://thezimouz.github.io/marlowby/

## Files

| File | What it is |
| --- | --- |
| `index.html` | Homepage (with the opening box animation) |
| `plans.html` | Subscription plans and pricing |
| `cities.html` | Featured cities and example boxes |
| `makers.html` | Local businesses and products |
| `subscribe.html` | Sign-up form |
| `about.html` | Company mission |
| `css/style.css` | All styling. Colors, fonts and spacing are at the top. |
| `js/main.js` | Shared JavaScript: active nav link, scroll fade-ins |

## How to edit

- Dashed gray boxes are placeholders. Replace each one with real content, then delete it.
- The nav bar and footer are copied on every page. If you change one, change all six.
- Save, commit and push. The live site updates in about a minute.
